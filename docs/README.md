# Документация проекта

## Начните отсюда

**[reference/](./reference/README.md) — техническая документация сайта.**
Описывает то, что работает сейчас: технологии, страницы, API, модель данных,
права, хранилище, конвейер, инструменты, статистика, интеграции, правила
интерфейса, эксплуатация. Плюс разбор дублирований и того, что стоит улучшить.

**`docs/DB_SCHEMA.html` — схема базы, снятая с живого сервера.**
Все таблицы с колонками, типами, ключами и допустимыми значениями; карта связей,
размеры на диске, темп прироста и физическое устройство хранения. Открывается в
браузере.

**Файла нет в репозитории — соберите его командой `npm run db:schema-doc`**
(нужен доступ к базе; путь и вёрстка — `scripts/db-schema-doc.mjs`). Он в
`.gitignore` намеренно: это снимок состояния на момент запуска, он устаревает
сам по себе и в коммитах давал бы только шум. Источник правды для DDL остаётся
прежним — `db/schema.sql` и `db/migrations/`.

**[TOOLS_DEV_GUIDE.md](./TOOLS_DEV_GUIDE.md) — как разработать инструмент для сайта.**
Что добавить, чтобы инструмент появился в каталоге; чем он имеет право дотянуться до
данных пользователя (проекты, файлы, описание, параметры обработки, чат, статистика);
дизайнерская база и каркас; свои серверные роуты; отдельно — что нужно решить для
админских инструментов, которым положен доступ к проектам любого пользователя.

**[CLEANUP_PLAN.md](./CLEANUP_PLAN.md) — задание на чистку.**
Четыре задачи: свести две поверхности storage API, убрать «Идеи», убрать старую
генерацию экранов кабинета, убрать наследие Google Drive. С доказательствами,
пошаговым порядком и чеклистом приёмки. Код по нему ещё не менялся.

Проверки, которые ловят расхождение кода с этими правилами:
`npm run i18n:check` (захардкоженные строки), `npm run md:check` (формат
описаний), `npm run admin:check` (недостижимые разделы админки).
Расхождение документации с базой видно в `npm run db:schema-doc`: новая таблица
без описания попадает на странице в область «Без области».

Остальные файлы в `docs/` — **контракты с внешними программами** и **планы**.
Они не описывают сайт целиком и местами описывают замысел, а не реальность.
